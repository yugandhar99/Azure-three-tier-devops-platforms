# Career Progression Notes – Azure

This project is designed to show progression from a basic three-tier application into a more complete DevOps/cloud platform implementation.

## Progression shown

1. **Application foundation** – React frontend, Spring Boot backend, and MySQL database.
2. **Containerization** – Dockerfiles and Docker Compose for repeatable local execution.
3. **CI/CD readiness** – Jenkinsfile and GitHub Actions portfolio validation.
4. **Infrastructure automation** – Terraform examples and backend configuration patterns.
5. **Cloud platform deployment** – Azure-focused deployment structure and architecture.
6. **Security and operations** – secrets hygiene, scanning workflow design, runbooks, and AI-ready release summary notes.

## Why this matters

The project is not just an application upload. It demonstrates how the same application can be prepared for professional delivery using modern DevOps practices: automation, documentation, cloud readiness, secure configuration, and operational thinking.
