# Screenshots to Add

Add screenshots after you run the project locally or deploy it. Recommended images:

- Application home page
- CI/CD workflow run passing
- Container image in registry
- Azure deployed resources
- Monitoring dashboard or logs
- Architecture diagram

Keep screenshots under `static/images/` and reference them from `README.md`.


## Generated portfolio visuals

When real cloud screenshots are not available, this repository includes generated visuals that explain the project clearly:

- `static/images/generated/*-portfolio-overview.png`
- `static/images/generated/*-career-progression.png`

These are intentionally included in the README so the project remains easy to understand for recruiters, interviewers, and GitHub visitors.
